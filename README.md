# 🤖 AkashAI — Personal AI Assistant

AkashAI is a desktop AI assistant built with Python, designed to provide a simple conversational interface and interact with an AI model.

## 🧠 About the Project

AkashAI was created as a personal project to explore:

- Python application development
- AI API integration
- Desktop GUI development
- Environment variables and API configuration
- Connecting a graphical interface with an AI backend

## 🛠️ Technologies Used

- Python
- CustomTkinter
- Google Gemini API
- `.env` environment configuration

## ✨ Features

- 💬 Conversational AI interface
- 🖥️ Desktop GUI
- 🤖 Gemini AI integration
- ⚡ Simple and responsive interface
- 🔐 API key stored using environment variables
